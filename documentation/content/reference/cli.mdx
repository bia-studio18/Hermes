# CLI Reference

Hermes provides a command-line interface built with [Typer](https://typer.tiangolo.com/). After installation, the `hermes` command is available in your shell.

## Usage

```bash
hermes [COMMAND] [OPTIONS]
```

## Commands

### `hermes version`

Print the current version.

```bash
$ hermes version
Hermes v0.2.16
```

> Note: the printed version is currently hardcoded to `v0.2.16` in the CLI while the package version is `0.2.17` — they will be synced.

### `hermes info`

Print version and description.

```bash
$ hermes info
Hermes v0.2.16
Foundational intelligence data platform
```

### `hermes profile_data <PATH>`

Profile a dataset file and display a rich-formatted report.

```bash
$ hermes profile_data gdp.csv
```

**Arguments:**

| Argument | Description |
|----------|-------------|
| `PATH` | Path to the dataset file (CSV or Parquet) |

The command displays:
- **Summary panel** — file path, row count, column count, date range, frequency
- **Columns table** — per-column stats: type, unique count, null count, null %, min, max, mean, median
- **Top values** — most frequent values per string column
- **Quality panel** — completeness, duplicate count, anomaly count

## Installation

The CLI is installed automatically with `pip install hermes-plt`. The entry point is defined in `pyproject.toml`:

```toml
[project.scripts]
hermes = "hermes.cli:app"
```

## Dependencies

The CLI uses:
- `typer` — command framework
- `rich` — terminal formatting and tables
