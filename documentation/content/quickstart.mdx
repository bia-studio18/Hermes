# Quickstart

Get Hermes running in under 5 minutes. This guide walks you through installation, basic configuration, and your first data pipeline.

## Install

Hermes requires **Python 3.11 or newer**. Install from PyPI:

```bash
pip install hermes-plt
```

Verify the installation:

```bash
hermes version
```

## Basic Usage

### Profile a local file

The fastest way to see Hermes in action — profile any CSV or Parquet file:

```python
import hermes as hr

# Profile a CSV file directly
report = hr.profile(path="data.csv")

print(report.row_count)
print(report.column_count)
for col in report.columns:
    print(f"{col.name}: {col.dtype}, nulls={col.null_count}, unique={col.unique_count}")
```

Or from the terminal:

```bash
hermes profile_data data.csv
```

### Read and inspect data

```python
import hermes as hr
import polars as pl

# Read a file into a DataFrame
df = pl.read_csv("gdp.csv")

# Quick inspection
info = hr.inspect(df)
print(f"rows: {info.row_count}, columns: {info.column_count}")
for col_name, col_type in info.columns:
    print(f"  {col_name}: {col_type}")
```

### Work with the Dataset object

The `Dataset` is Hermes' core abstraction — it holds your data alongside its metadata, provenance, and lineage:

```python
import hermes as hr
import polars as pl

df = pl.read_csv("gdp.csv")

# Create a Dataset
ds = hr.Dataset(
    name="gdp",
    data_ref="gdp.csv",
    data=df,
)

# Profile it (populates metadata)
ds.profile()

# Inspect the data
report = ds.inspect()
print(f"rows: {report.row_count}, columns: {report.column_count}")

# Access metadata
print(ds.metadata_info())
print(ds.provenance_info())
print(ds.lineage_info())
```

### Export data

```python
# Save to different formats
ds.save("output/", format="parquet")   # writes output/gdp.parquet
ds.save("output/", format="csv")       # writes output/gdp.csv
ds.save("output/", format="json")      # writes output/gdp.json

# Or export to raw bytes
csv_bytes = ds.export("csv")
parquet_bytes = ds.export("parquet")
```

### Interoperate with your stack

```python
# Convert to any format your tools expect
polars_df = ds.to_polars()   # polars.DataFrame
arrow_tbl = ds.to_arrow()    # pyarrow.Table
pandas_df = ds.to_pandas()   # pandas.DataFrame
```

## Connectors

Hermes ships with 10 source connectors that share a common disk cache and retry layer. Connectors are used directly (they are `async`), and each `fetch()` caches its result by default.

### World Bank (no API key required)

```python
import asyncio
from hermes.connectors import World_bank

async def main():
    wb = World_bank()  # uses the shared disk cache (~/.hermes_cache/raw)

    df = await wb.fetch(
        country_code="US",
        indicator_code="NY.GDP.MKTP.KD.ZG",
    )
    print(df.head())

asyncio.run(main())
```

### FRED (requires API key)

```python
from hermes.connectors import FRED

fred = FRED(api="your_fred_key")

df = await fred.fetch(series_id="CPIAUCSL")  # Consumer Price Index
print(df.head())
```

### Binance (no API key required)

```python
from hermes.connectors import Binance

b = Binance()

# Single request (cached): 30 daily spot candles
df = await b.fetch(mode="spot", endpoint="ohlcv", symbol="BTCUSDT", interval="1d", limit=30)
print(df.head())

# Multi-year history (future market, up to 10 concurrent requests)
history = await b.fetch_history(symbol="BTCUSDT", interval="1d", market="future", years=2)
print(history.head())
```
