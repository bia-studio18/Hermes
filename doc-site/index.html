hermes quickstart python 
import hermes as hr
import polars as pl

# Load your data
df = pl.read_csv("gdp.csv")

# Full statistical profile
report = hr.profile(df)
print("rows:", report.row_count, "· columns:", report.column_count)
print("date range:", report.date_range)
print("duplicates:", report.quality.duplicate_count)

# Wrap in Dataset — data plus its story
ds = hr.Dataset(name="gdp", data_ref="gdp.csv", data=df)
ds.profile()
ds.inspect()

# Interoperate with your stack
polars_df = ds.to_polars()
arrow_tbl = ds.to_arrow()
pandas_df = ds.to_pandas()

# Persist with provenance
ds.save("out", format="parquet")
csv_bytes = ds.export("csv")
Introduction

Hermes is the pipeline layer
around your existing stack.

It is not another dataframe library. Hermes sits between data sources and your models — it brings data in, understands it, cleans and validates it, and makes it ready for analysis and machine learning. No cloud account. No hosted service. No proprietary storage required.

python 
import hermes as hr
import polars as pl

df = pl.read_csv("gdp.csv")

# The Dataset: data + story
ds = hr.Dataset(
    name="gdp",
    data_ref="gdp.csv",
    data=df,
)

# Profile: statistical understanding
ds.profile()

# Access the full story
ds.metadata_info    # column stats, quality, dates
ds.provenance_info  # source, connector, checksum
ds.lineage_info     # load → profile operations
ds.schema_info      # canonical schema reference

# Convert to your stack
ds.to_polars()     # → pl.DataFrame
ds.to_arrow()      # → pa.Table
ds.to_pandas()     # → pd.DataFrame

# Persist
ds.save("out", format="parquet")
csv_bytes = ds.export("csv")
