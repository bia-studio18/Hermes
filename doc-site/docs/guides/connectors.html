Connectors Guide

Fetching data from external sources using Hermes connectors.

Overview

Hermes ships with 10 built-in connectors for financial, economic, and geopolitical data. Each connector lives in its own module under hermes/connectors/.

Available Connectors

  • Binance — Crypto market data (klines, trades, ticker)
  • FRED — US economic indicators from the Federal Reserve
  • World Bank — Global development indicators
  • SEC EDGAR — US corporate filings (10-K, 10-Q, 8-K)
  • YFinance — Stock market data from Yahoo Finance
  • Finnhub — Financial market data and news
  • IMF — Macroeconomic data from the IMF
  • GDELT — Geopolitical event data
  • OpenSanctions — Sanctions and politically exposed persons
  • Public Datasets — Curated public datasets

Using Connectors

Each connector follows a common pattern: instantiate it with any required credentials, then call its fetch method with the appropriate parameters:

from hermes.connectors import fred

# Fetch GDP data from FRED
data = fred.fetch(series_id="GDP", start_date="2020-01-01")

Exact parameters vary by connector. See the Connectors API Reference for details on each connector.

Authentication

Some connectors require API keys. Pass them as constructor arguments:

from hermes.connectors import finnhub

connector = finnhub.FinnhubConnector(api_key="your-key")

If credentials are missing, the connector raises AuthenticationError.

Error Handling

  • ConnectorNotFoundError — The requested connector name doesn't exist.
  • AuthenticationError — API key is missing or invalid.
  • AcquisitionError — Network or API error during fetch.

Adding Custom Connectors

To add a new connector, create a module under hermes/connectors/ and follow the existing pattern. See Adding Connectors for a step-by-step guide.
