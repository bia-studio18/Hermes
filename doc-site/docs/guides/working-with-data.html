Working with Data

Practical techniques for loading, profiling, and inspecting data with Hermes.

Loading Data

Hermes works with Polars DataFrames as its primary data format. Load data from files directly:

import polars as pl

# CSV
df = pl.read_csv("data.csv")

# Parquet
df = pl.read_parquet("data.parquet")

# JSON
df = pl.read_json("data.json")

Profiling Data

Use hr.profile() to get a comprehensive statistical summary:

import hermes as hr

meta = hr.profile(data=df)
print(meta)

You can also profile directly from a file path:

meta = hr.profile(path="data.csv")

The MetaData object contains column-level statistics (types, nulls, distributions), row count, and quality scores.

Inspecting Data

For a quick overview without full profiling, use hr.inspect():

report = hr.inspect(df)
print(report.row_count)     # 3
print(report.column_count)  # 3
print(report.columns)       # [('date', 'str'), ('price', 'f64'), ('volume', 'i64')]
print(report.sample)        # first 5 rows as dicts

Detecting Time-Series Frequency

Find the frequency of a time column:

freqs = hr.get_freqs(df)
print(freqs)  # ['daily'], ['weekly'], ['monthly'], or None

The hr.get_freqs() function (hermes/api/data.py:69) examines datetime columns and attempts to identify a consistent frequency.

Finding Date Ranges

Identify date ranges for each datetime column:

ranges = hr.date_ranges(df)
print(ranges)
# [{'date': (datetime(2024, 1, 1), datetime(2024, 12, 31))}]

Detecting Anomalies

Count outliers using the IQR method:

result = hr.anomaly_count(df, threshold=1.5)
print(result)
# {'price': 3, 'volume': 1}

The threshold parameter controls the IQR multiplier (default 1.5). Higher values are less sensitive.

Converting Between Formats

If you need to convert between DataFrame libraries:

import hermes as hr

ds = hr.Dataset(name="my_data", data_ref="data.csv", data=df)

# To Pandas
pdf = ds.to_pandas()

# To PyArrow
tbl = ds.to_arrow()

# Back to Polars
df = ds.to_polars()
