Entities Guide

Resolving and normalizing real-world entities in your data.

Overview

The entities module helps you match, resolve, and normalize references to countries, companies, and people across different data sources.

Country Resolution

Convert between ISO-3166 codes and country names:

from hermes.entities import countries, iso3_to_iso2

# Get all countries
print(len(countries))  # 200+

# Convert alpha-3 to alpha-2
print(iso3_to_iso2["USA"])  # "US"
print(iso3_to_iso2["GBR"])  # "GB"

Using the Entity Model

from hermes.entities import Entity

entity = Entity(
    name="Apple Inc.",
    type="company",
    identifiers={"cusip": "037833100", "isin": "US0378331005"},
)
print(entity)

Entity Matching

When data from different sources refers to the same entity with different identifiers, EntityMatch captures the resolution:

from hermes.entities import EntityMatch

match = EntityMatch(
    input="Apple Inc",
    matched=entity,
    confidence=0.95,
)
print(match)

Custom Resolvers

Implement the Resolver ABC for custom entity resolution logic (e.g., API lookups, fuzzy matching, database joins).
