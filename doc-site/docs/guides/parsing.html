Parsing Guide

Reading CSV, JSON, Parquet, and XML files into DataFrames.

Overview

Hermes includes four parsers, each handling a different file format. They all return Polars DataFrames.

Reading CSV

import polars as pl

# With Polars directly
df = pl.read_csv("data.csv")

# With Hermes parser
from hermes.parsing import CSVParser
parser = CSVParser()
df = parser.parse("data.csv")

Reading JSON

import polars as pl

# JSON Lines
df = pl.read_ndjson("data.jsonl")

# Standard JSON
df = pl.read_json("data.json")

Reading Parquet

import polars as pl
df = pl.read_parquet("data.parquet")

Reading XML

from hermes.parsing import XMLParser
parser = XMLParser()
df = parser.parse("data.xml")

The XML parser uses lxml to handle complex XML structures and flatten them into tabular form.

Using ParserEngine

The ParserEngine dispatches to the correct parser based on file extension:

from hermes.parsing import ParserEngine

engine = ParserEngine()
df = engine.parse("data.csv")  # Auto-detects CSV
df = engine.parse("data.json")  # Auto-detects JSON

Best Practices

  • For large files, prefer Parquet for faster reads and lower memory usage.
  • For CSV files with mixed types, use Polars' dtypes parameter to specify column types explicitly.
  • For XML, consider flattening nested structures during parsing to avoid deeply nested DataFrames.
