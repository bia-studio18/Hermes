Development Setup

Setting up a development environment for Hermes.

Prerequisites

  • Python 3.11 or later
  • git
  • pip or uv (recommended)

Clone the Repository

git clone https://github.com/anomalyco/hermes.git
cd hermes

Install in Development Mode

pip install -e ".[dev]"

Or with uv:

uv pip install -e ".[dev]"

Verify Installation

hermes version
python -c "import hermes; print(hermes.__version__)"

Run Tests

pytest tests/

Code Quality

ruff check hermes/
ruff format hermes/
