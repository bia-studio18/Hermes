Testing

Running and writing tests for Hermes.

Running Tests

pytest tests/

Running Specific Tests

# Run a specific test file
pytest tests/test_dataset.py

# Run a specific test function
pytest tests/test_dataset.py::test_dataset_creation

# Run tests matching a pattern
pytest -k "profile"

Test Structure

tests/
test_dataset.py       # Dataset tests
test_metadata.py      # Metadata and profiling tests
test_connectors.py    # Connector tests
test_parsing.py       # Parser tests
test_validation.py    # Validation tests
test_entities.py      # Entity resolution tests
...

Writing Tests

Tests use pytest and follow standard conventions:

import pytest
import hermes as hr
import polars as pl

def test_profile_returns_metadata():
    df = pl.DataFrame({"price": [1.0, 2.0, 3.0]})
    meta = hr.profile(data=df)
    assert meta is not None

def test_inspect_returns_report():
    df = pl.DataFrame({"price": [1.0, 2.0, 3.0]})
    report = hr.inspect(df)
    assert report.row_count == 3
    assert report.column_count == 1
