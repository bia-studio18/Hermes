Quickstart

Load, profile, and inspect a real dataset in five minutes.

Setup

pip install hermes-plt

Profile a CSV File

import hermes as hr

meta = hr.profile(path="prices.csv")
print(meta)

The hr.profile() function accepts a path parameter (string or Path) and returns a MetaData object. It reads the file with Polars, computes column statistics, and wraps everything in a structured metadata report.

Profile a DataFrame

import hermes as hr
import polars as pl

df = pl.DataFrame({
    "date": ["2024-01-01", "2024-01-02", "2024-01-03"],
    "price": [100.0, 102.5, 98.3],
    "volume": [1000, 1500, 800],
})

meta = hr.profile(data=df)
print(meta)

Quick Inspection

report = hr.inspect(df)
print(report.row_count)     # 3
print(report.column_count)  # 3
print(report.columns)       # [('date', 'str'), ('price', 'f64'), ('volume', 'i64')]
print(report.sample)        # [{'date': '2024-01-01', 'price': 100.0, ...}, ...]

hr.inspect() returns an InspectReport with row count, column count, column names/types, and a sample of the first 5 rows.

Detect Time-Series Frequency

freqs = hr.get_freqs(df)
print(freqs)  # ['daily'] or None if no frequency detected

Find Date Ranges

ranges = hr.date_ranges(df)
print(ranges)
# [{'date': (datetime(2024, 1, 1), datetime(2024, 1, 3))}]

Count Anomalies

result = hr.anomaly_count(df, threshold=1.5)
print(result)  # {'price': 0, 'volume': 0}

Uses the IQR method. Points beyond Q1 - threshold * IQR or Q3 + threshold * IQR are flagged.

Create a Dataset

ds = hr.Dataset(
    name="prices",
    data_ref="data/prices.csv",
    data=df,
    version="0.0.1",
)

# Access metadata
print(ds.metadata_info())

# Access provenance
print(ds.provenance_info())

# Convert to other formats
pandas_df = ds.to_pandas()
arrow_table = ds.to_arrow()

CLI Usage

hermes profile_data data.csv

Equivalent to hr.profile(path="data.csv") from the command line.
