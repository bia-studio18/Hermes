Storage

Pluggable backends for persisting and querying datasets.

Overview

The storage layer provides a pluggable abstraction for persisting datasets. Hermes defines a StorageBackend abstract base class and ships with three concrete implementations.

Storage Backends

BackendFormatModule
ParquetStorageApache Parquet fileshermes/storage/parquet_storage.py
DuckDBStorageDuckDB databasehermes/storage/duckdb_storage.py
FilesystemStorageGeneric filesystemhermes/storage/filesystem_storage.py

StorageBackend ABC

All storage backends implement the StorageBackend abstract base class, which defines the interface for reading, writing, listing, and deleting datasets.

Current Status

All three backends are defined but currently raise NotImplementedError. They are planned for a future release.

  • hr.save() — Planned
  • hr.load() — Planned

Error Handling

Storage errors are wrapped in StorageError (from hermes/core/errors.py).
