Datasets

The central abstraction in Hermes: a data object that carries its own story.

Overview

A Dataset is the primary object you work with in Hermes. It wraps a Polars DataFrame and bundles it with metadata, provenance, lineage, and schema information. A Dataset is serializable — you can save it to disk and reload it later with the full audit trail intact.

Creating a Dataset

import hermes as hr
import polars as pl

df = pl.read_csv("prices.csv")

ds = hr.Dataset(
    name="prices",
    data_ref="data/prices.csv",
    data=df,
    version="0.0.1",
    schema_ref="market.observation",
)

Parameters:

  • name — A human-readable name for the dataset.
  • data_ref — A reference to the original data source (file path, URL, etc.).
  • data — The actual Polars DataFrame (optional; can be loaded later).
  • version — Semantic version string (default "0.0.1").
  • schema_ref — Reference to a canonical schema (optional).

Dataset Methods

MethodReturnsDescription
.load()NoneLoad data from data_ref if not already loaded
.inspect()InspectReportQuick shape/dtype/memory summary
.profile()MetaDataFull statistical profiling
.to_polars()pl.DataFrameGet the underlying Polars DataFrame
.to_arrow()pa.TableConvert to PyArrow Table
.to_pandas()pd.DataFrameConvert to Pandas DataFrame
.save()NonePersist dataset to disk
.export()NoneExport to various formats
.metadata_info()dictGet metadata summary
.provenance_info()dictGet provenance record
.lineage_info()dictGet transformation lineage
.schema_info()dictGet schema information

Interoperability

Datasets are designed to work with the broader Python data ecosystem:

df = ds.to_polars()    # Polars DataFrame
tbl = ds.to_arrow()    # PyArrow Table
pdf = ds.to_pandas()   # Pandas DataFrame
