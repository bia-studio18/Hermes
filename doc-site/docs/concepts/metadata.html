Metadata

Statistical summaries and quality information for your data.

Overview

Metadata in Hermes captures the statistical properties of your data: column types, distributions, null rates, quality scores, and more. It is produced by the hr.profile() function and stored on the Dataset.

Metadata Classes

  • MetaData — The top-level metadata object returned by hr.profile(). Contains column-level metadata, row count, and quality summary.
  • ColumnMetadata — Per-column statistics: type, null count, min, max, mean, median, std, unique count, and distribution.
  • QualityInfo — Overall quality scores: completeness, consistency, and accuracy ratings.
  • InspectReport — A lighter-weight report from hr.inspect() with shape, dtypes, and memory usage.

Profiling

import hermes as hr

meta = hr.profile(path="data.csv")
print(meta)  # Full statistical summary

# Or with a DataFrame
import polars as pl
df = pl.read_csv("data.csv")
meta = hr.profile(data=df)

The hr.profile() function (hermes/api/data.py:127) accepts either a data parameter (DataFrame) or a path parameter (file path) or a source parameter (data source reference). It returns a MetaData object.

Quick Inspection

report = hr.inspect(df)
print(report.row_count)       # 1000
print(report.column_count)    # 5
print(report.columns)         # [('date', 'Utf8'), ('price', 'Float64'), ...]

The hr.inspect() function (hermes/api/data.py:41) returns an InspectReport with a fast summary.

Quality Scores

QualityInfo provides three quality dimensions:

  • Completeness — Percentage of non-null values.
  • Consistency — How well values conform to expected types and ranges.
  • Accuracy — Statistical plausibility of values.
