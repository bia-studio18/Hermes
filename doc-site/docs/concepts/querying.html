Querying

Filtering, selecting, sorting, aggregating, and joining data.

Overview

The query engine (hermes/query/) provides a structured API for common data operations. It supports filter, select, sort, aggregate, join, and SQL operations.

QueryEngine

The QueryEngine accepts a DataFrame and provides methods for each operation:

  • filter() — Apply row-level conditions.
  • select() — Choose specific columns.
  • sort() — Order by one or more columns.
  • aggregate() — Group and compute summaries.
  • join() — Combine two DataFrames.
  • sql() — Execute raw SQL via DuckDB.

Current Status

The QueryEngine is defined. The top-level convenience function is not yet wired up:

  • hr.query() — Planned
  • hr.materialize() — Planned

In the meantime, you can query data directly with Polars:

import polars as pl

df = pl.read_csv("data.csv")

# Filter
filtered = df.filter(pl.col("price") > 100)

# Sort
sorted_df = df.sort("date", descending=True)

# Aggregate
aggregated = df.group_by("category").agg(pl.col("price").mean())

Error Handling

Query errors are wrapped in QueryError (from hermes/core/errors.py).
