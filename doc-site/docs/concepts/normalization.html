Normalization

Transforming raw data into consistent, well-typed formats.

Overview

Normalization is the process of cleaning and transforming raw data so that it conforms to expected formats and types. The NormalizationEngine (hermes/normalization/) applies a series of rules to columns in a DataFrame.

Built-in Rules

RulePurpose
DateNormalizationRuleParse date strings into consistent datetime types
NumericNormalizationRuleClean numeric strings (remove currency symbols, handle thousands separators)
FieldMappingRename columns to canonical names

NormalizationEngine

The engine accepts a DataFrame and a list of rules. It applies each rule to the specified column(s) and returns a new DataFrame with the transformations applied. The engine also records each transformation in the lineage metadata.

Current Status

The NormalizationEngine and its built-in rules are implemented. The top-level convenience function is not yet wired up:

  • hr.normalize() — Planned

You can use the engine directly via NormalizationEngine from hermes/normalization/.

Error Handling

Normalization errors are wrapped in NormalizationError (from hermes/core/errors.py). These typically indicate unparseable values or type mismatches.
