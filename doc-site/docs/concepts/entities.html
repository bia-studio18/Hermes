Entities

Resolving and normalizing real-world entities: countries, companies, and people.

Overview

The entities module (hermes/entities/) provides tools for matching, resolving, and normalizing references to real-world entities. This is critical when data from multiple sources uses different identifiers for the same entity (e.g., "US", "USA", "United States", "840").

Entity Model

The Entity model represents a resolved entity with standardized fields: name, type, identifiers, and metadata.

EntityMatch

EntityMatch captures the result of an entity resolution attempt, including the matched entity, confidence score, and the original input.

Countries

Hermes includes a built-in list of 200+ countries with ISO-3166 alpha-2 and alpha-3 codes. The iso3_to_iso2 mapping converts between the two standards.

from hermes.entities import countries, iso3_to_iso2

print(len(countries))  # 200+
print(iso3_to_iso2["USA"])  # "US"

Resolver

The Resolver ABC (hermes/entities/) defines the interface for custom entity resolvers. Implementations can use fuzzy matching, API lookups, or database joins to resolve entities.

Current Status

The Entity model, EntityMatch, countries list, and iso3_to_iso2 mapping are implemented. The top-level convenience functions are not yet wired up:

  • hr.resolve_entity() — Planned
  • hr.resolve_country() — Planned
  • hr.resolve_company() — Planned
