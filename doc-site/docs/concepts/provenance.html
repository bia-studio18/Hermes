Provenance

Tracking where your data came from and how it was retrieved.

Overview

Provenance captures the origin of your data: which source it came from, when it was retrieved, and which connector was used. This is the foundation of auditable data pipelines.

Provenance Fields

The Provenance class (hermes/core/provenance.py) tracks:

FieldDescription
sourceOriginal data source identifier
endpointSpecific API endpoint or file path
retrieved_atTimestamp when the data was fetched
connectorName of the connector used
connector_versionVersion of the connector at retrieval time
raw_checksumSHA-256 checksum of the raw response
parser_versionVersion of the parser used
normalizer_versionVersion of the normalizer used
schema_versionVersion of the schema applied

Accessing Provenance

ds = hr.Dataset(name="prices", data_ref="data.csv", data=df)
print(ds.provenance_info())

Why Provenance Matters

When a number in your dashboard looks wrong, provenance lets you trace it back to the exact API call, the exact timestamp, and the exact version of the code that produced it. This is essential for reproducibility and debugging.
