Documentation

How to contribute to Hermes documentation.

Overview

The Hermes documentation site is built with static HTML pages. Each page follows the same template and is hosted in the doc-site/ directory.

Documentation Structure

doc-site/
index.html             # Landing page
css/hermes.css         # Shared styles
js/hermes.js           # Shared scripts
docs/
  introduction/        # Overview, What is Hermes, Getting Started
  installation/        # Installation guide
  quickstart/          # Quickstart tutorial
  concepts/            # Core concepts (13 pages)
  guides/              # Practical guides (9 pages)
  api/                 # API reference (12 pages)
  cli/                 # CLI reference (3 pages)
  architecture/        # Architecture (7 pages)
  development/         # Development guides (6 pages)
  contributing/        # Contributing guides (6 pages)

Adding a Page

  1. Create the HTML file in the appropriate directory.
  2. Copy the template structure from an existing page.
  3. Set the correct active sidebar link.
  4. Set the correct title and section name.
  5. Write the content and TOC links.

Guidelines

  • Use real API names and function signatures from the source code.
  • Mark planned features with <span class="badge badge-plan">Planned</span>.
  • Include code examples that use actual, working APIs.
  • Keep pages focused on a single topic.

Template Variables

Each page must set:

  • <title> — PAGE_TITLE — Hermes
  • d-logo-section — Section name (e.g., "Introduction", "API Reference")
  • d-sidebar-link active — The current page's sidebar link
