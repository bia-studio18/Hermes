Adding Parsers

Step-by-step guide for adding a new file format parser.

Overview

Parsers live under hermes/parsing/. Each parser reads a specific file format and returns a Polars DataFrame.

Steps

  1. Create the module: Add hermes/parsing/my_format_parser.py.
  2. Implement the parser class: Accept a file path, read the file, return a Polars DataFrame.
  3. Register with ParserEngine: Add format detection logic.
  4. Write tests: Add test cases with sample files.

Example

# hermes/parsing/my_format_parser.py
import polars as pl

class MyFormatParser:
    def parse(self, path: str) -> pl.DataFrame:

Guidelines

  • Use Polars as the output format.
  • Infer column types when possible.
  • Handle encoding issues gracefully.
  • Raise ParseError for malformed input.
