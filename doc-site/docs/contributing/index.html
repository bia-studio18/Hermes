Contribution Workflow

How to contribute to Hermes.

Overview

Hermes welcomes contributions from the community. This guide covers the workflow for submitting changes.

Workflow

  1. Fork the repository on GitHub.
  2. Clone your fork locally.
  3. Create a branch for your change: git checkout -b feature/my-feature
  4. Make your changes following the coding guidelines.
  5. Run tests to make sure nothing is broken: pytest tests/
  6. Run linter to check code quality: ruff check hermes/
  7. Commit with a clear, descriptive message.
  8. Push your branch to your fork.
  9. Open a Pull Request on the main repository.

Pull Request Guidelines

  • Keep PRs focused on a single change.
  • Include tests for new functionality.
  • Update documentation if adding or changing public APIs.
  • Make sure CI passes before requesting review.
