Parsing API

Reference for CSV, JSON, Parquet, and XML parsers.

ParserEngine

Module: hermes/parsing/

Central dispatcher that detects file format and delegates to the appropriate parser.

CSVParser

Module: hermes/parsing/csv_parser.py

Parses CSV and TSV files into Polars DataFrames. Handles delimiters, encoding, and type inference.

JSONParser

Module: hermes/parsing/json_parser.py

Parses JSON and JSON Lines files. Flattens nested structures into tabular form.

ParquetParser

Module: hermes/parsing/parquet_parser.py

Reads Apache Parquet files. Preserves column types and handles nested structures.

XMLParser

Module: hermes/parsing/xml_parser.py

Parses XML files using lxml. Flattens nested elements into tabular form.
