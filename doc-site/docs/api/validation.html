Validation API

Reference for validate(), NotNull, DataContract, and ValidationReport.

validate()

Runs a list of validation checks against a DataFrame. Returns a ValidationReport.

NotNull

A validation check that verifies a column has no null values.

from hermes.validation import NotNull
check = NotNull("price")

DataContract

A declarative specification of expected data structure: required columns, types, and nullability.

from hermes.validation import DataContract

contract = DataContract(
    required_columns=["date", "price"],
    column_types={"price": "Float64"},
    nullable={"price": False},
)
report = contract.validate(df)

ValidationReport

Contains status (pass/fail), errors, and warnings from a validation run.
