Export API

Exporting data to various formats.

Overview

The export module provides functionality for writing datasets to different file formats and destinations.

Dataset Methods

The Dataset class provides two methods for exporting data:

Dataset.save(path, format)

Export the dataset to a file on disk.

ds.save("output", format="parquet")
ds.save("output", format="csv")
ds.save("output", format="json")

Dataset.export(format)

Export to bytes or return as an object (polars, arrow, pandas).

csv_bytes = ds.export("csv")       # bytes
json_bytes = ds.export("json")     # bytes
pq_bytes = ds.export("parquet")    # bytes
df = ds.export("polars")           # pl.DataFrame
tbl = ds.export("arrow")           # pa.Table
pdf = ds.export("pandas")          # pd.DataFrame

Top-Level API

The top-level hr.save() function is not yet implemented:

  • hr.save(data, path, format) — Planned

Workaround

You can export data directly with Polars:

import polars as pl

df = pl.read_csv("data.csv")

# To Parquet
df.write_parquet("output.parquet")

# To CSV
df.write_csv("output.csv")

# To JSON
df.write_json("output.json")

# To Arrow IPC
df.write_ipc("output.arrow")

Converting via Dataset

import hermes as hr

ds = hr.Dataset(name="my_data", data_ref="data.csv", data=df)

# Get native frames for export
pandas_df = ds.to_pandas()
arrow_tbl = ds.to_arrow()
polars_df = ds.to_polars()
