Normalization API

Reference for the NormalizationEngine and built-in rules.

NormalizationEngine

Module: hermes/normalization/

Applies a sequence of normalization rules to a DataFrame. Returns a new DataFrame with transformations applied.

DateNormalizationRule

Parses date strings into consistent datetime types. Accepts a column name and a format string.

NumericNormalizationRule

Cleans numeric strings by removing currency symbols, handling thousands separators, and converting to numeric types.

FieldMapping

Renames columns to canonical names using a dictionary mapping.

Top-Level API

hr.normalize() — Planned

Error Handling

Normalization errors are wrapped in NormalizationError from hermes/core/errors.py.
