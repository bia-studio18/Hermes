Entities API

Reference for Entity, EntityMatch, Resolver, and country utilities.

Entity

Module: hermes/entities/

Represents a resolved entity (company, person, country) with standardized fields and identifiers.

EntityMatch

Captures the result of an entity resolution attempt: matched entity, confidence score, and original input.

Resolver

Abstract base class for custom entity resolvers. Implement resolve() for custom logic.

countries

A list of 200+ countries with ISO-3166 data.

iso3_to_iso2

Mapping from ISO-3166 alpha-3 to alpha-2 codes.

from hermes.entities import iso3_to_iso2
print(iso3_to_iso2["USA"])  # "US"
