Connectors API

Reference for all 10 built-in connectors.

Overview

Each connector lives in its own module under hermes/connectors/. They follow a common interface for fetching data from external APIs.

Binance

Module: hermes/connectors/binance.py

Fetches crypto market data (klines, trades, ticker) from the Binance API.

FRED

Module: hermes/connectors/fred.py

Fetches US economic indicators from the Federal Reserve Economic Data (FRED) API.

from hermes.connectors import fred
data = fred.fetch(series_id="GDP", start_date="2020-01-01")

World Bank

Module: hermes/connectors/world_bank.py

Fetches global development indicators from the World Bank Open Data API.

SEC EDGAR

Module: hermes/connectors/sec_edgar.py

Fetches US corporate filings (10-K, 10-Q, 8-K) from SEC EDGAR.

YFinance

Module: hermes/connectors/yfinance.py

Fetches stock market data from Yahoo Finance.

Finnhub

Module: hermes/connectors/finnhub.py

Fetches financial market data and news from the Finnhub API.

IMF

Module: hermes/connectors/imf.py

Fetches macroeconomic data from the International Monetary Fund.

GDELT

Module: hermes/connectors/gdelt.py

Fetches geopolitical event data from the GDELT Project.

OpenSanctions

Module: hermes/connectors/opensanctions.py

Fetches sanctions and politically exposed persons data from OpenSanctions.

Public Datasets

Module: hermes/connectors/public_datasets.py

Access curated public datasets.

Error Handling

  • ConnectorNotFoundError — Unknown connector name.
  • AuthenticationError — Missing or invalid API credentials.
  • AcquisitionError — Network or API errors.
