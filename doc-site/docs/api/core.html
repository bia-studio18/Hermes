Core API

Dataset, Result, errors, metadata, provenance, lineage, and versioning.

Dataset

Module: hermes/core/dataset.py

class Dataset:
    def __init__(
        self,
        name: str,
        data_ref: str | Path,
        data: pl.DataFrame | None = None,
        version: str = "0.0.1",
        schema_ref: str | None = None,
    )

The central abstraction. Wraps a Polars DataFrame with metadata, provenance, lineage, and schema information.

Result

Module: hermes/core/result.py

A generic result wrapper with status, data, errors, and warnings. Used by pipeline stages to return structured outcomes.

class Result:
    status: Literal["success", "warning", "partial", "failure"]
    data: Any = None
    metadata: dict[str, Any] | None = None
    statistics: dict[str, Any] | None = None
    errors: list[ResultError] = []
    warnings: list[str] = []

    def add_error(self, error: BaseException, **details) -> None: ...
    def is_success(self) -> bool: ...
    def is_failure(self) -> bool: ...
    def raise_if_failure(self) -> None: ...

class ResultError:
    code: str
    message: str
    details: dict[str, Any] | None = None

Error Hierarchy

Module: hermes/core/errors.py

HermesError           # Base class
├── AcquisitionError  # Data fetching errors
│   ├── ServerError      # 5xx remote errors (retryable)
│   ├── RateLimitError   # Rate limit exceeded (has retry_after)
│   └── TimeoutError     # Request timed out
├── ParseError        # File parsing errors
├── SchemaError       # Schema errors
├── NormalizationError # Normalization errors
├── ValidationError   # Validation errors
├── StorageError      # Storage errors
├── QueryError        # Query errors
├── ConfigError       # Configuration errors
├── ConnectorNotFoundError  # Unknown connector
└── AuthenticationError     # Missing/invalid credentials

Metadata

Module: hermes/core/metadata.py

  • MetaData — Top-level metadata from hr.profile()
  • ColumnMetadata — Per-column statistics
  • QualityInfo — Quality metrics (completeness per column, duplicate count, anomaly count per numeric column)
  • InspectReport — Lightweight report from hr.inspect()

Provenance

Module: hermes/core/provenance.py

Tracks: source, endpoint, retrieved_at, connector, connector_version, raw_checksum, parser_version, normalizer_version, schema_version.

Lineage

Module: hermes/core/lineage.py

A list of steps, each recording: operation, input_ref, output_ref, output_schema, timestamp, params, component_version.

DataVersion

Module: hermes/core/versioning.py

Tracks content_hash, schema_hash, created_at, parent_version for data versioning.
