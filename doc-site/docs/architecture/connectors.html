Connectors Architecture

How connectors are structured and how to add new ones.

Design

Each connector is a self-contained module under hermes/connectors/. Connectors handle authentication, HTTP requests, and data transformation for a specific external API.

Common Pattern

from hermes.connectors import my_connector

# Fetch data
data = my_connector.fetch(param1="value1", param2="value2")

Error Handling

  • ConnectorNotFoundError — Unknown connector name.
  • AuthenticationError — Missing or invalid credentials.
  • AcquisitionError — Network or API errors.

Adding a New Connector

  1. Create a new module under hermes/connectors/.
  2. Implement the fetch function with the connector-specific logic.
  3. Handle authentication via constructor parameters.
  4. Raise appropriate errors from hermes.core.errors.

See Adding Connectors for a detailed guide.

Caching

The RawCache (hermes/acquisition/cache.py) can be used by connectors to cache raw API responses with a configurable TTL.
