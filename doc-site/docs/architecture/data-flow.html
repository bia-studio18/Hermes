Data Flow

How data moves through the Hermes pipeline.

The Pipeline

Data flows through Hermes in a linear pipeline. Each stage transforms the data and records its actions in the lineage metadata.

Source (API/File)
    |
    v
+----------------+
|  Acquisition   |  -- RawCache stores raw response

+----------------+
|    Parsing     |  -- ParserEngine -> Polars DataFrame
+----------------+
    |

+----------------+

+----------------+
    |
    v
+----------------+

+----------------+
    |
    v
+----------------+
|  Profiling     |  -- hr.profile() -> MetaData
+----------------+
    |
    v
+----------------+
|    Dataset     |  -- Bundles data + metadata + provenance + lineage
+----------------+

What is Implemented

In v0.2.16, the main entry points are:

  • hr.profile() — Reads data and generates full statistical profiling in one step.
  • hr.inspect() — Quick shape/dtype snapshot.
  • hr.get_freqs(), hr.date_ranges(), hr.anomaly_count() — Analytical functions.
  • Dataset — Bundles everything into a single object.

Planned Pipeline

The full pipeline stages are planned for future releases. Currently, each stage works independently but the orchestration layer (hr.fetch(), hr.parse(), hr.normalize(), hr.validate()) raises NotImplementedError.
