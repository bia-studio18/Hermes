Core Abstractions

The fundamental types and patterns in Hermes.

Dataset

The central abstraction. A Dataset wraps a Polars DataFrame and carries metadata, provenance, lineage, and schema information. It is serializable and serves as the single auditable object.

Result

A generic wrapper for pipeline outputs. Contains status ("ok" or "error"), data, errors list, and warnings list. Every pipeline stage returns a Result.

Error Hierarchy

All Hermes errors extend HermesError. This allows catching all Hermes-specific errors with a single handler while still being able to catch specific error types:

try:
    result = hr.profile(path="data.csv")
except AcquisitionError:
    ...
except ParseError:
    ...
except HermesError:
    ...

Metadata

Statistical information about data. MetaData contains ColumnMetadata for each column and a QualityInfo summary.

Provenance

Tracks the origin of data: source, endpoint, retrieval time, connector, and checksums.

Lineage

Records every transformation as a step with operation, input/output references, timestamp, and parameters.

DataVersion

Tracks content hashes and parent versions for data versioning.

ValidationReport

Structured output from validation: status, errors, and warnings.

InspectReport

Lightweight report from hr.inspect(): shape, dtypes, memory usage.
