Hermes Documentation

A local-first, auditable data platform for financial, economic, and geopolitical data.

Hermes is an open-source Python toolkit that brings together data acquisition, parsing, normalization, validation, and querying into a single cohesive library. Every dataset is wrapped in a Dataset object that carries not just the data, but the complete story of where it came from, how it was transformed, and what schema it conforms to.

Current Version

Hermes v0.2.16 is available now via pip install hermes-plt. It requires Python 3.11 or later and is licensed under the Elastic License 2.0.

What Works Now

Hermes v0.2.16 provides a solid foundation for working with structured data:

  • Data Profiling — hr.profile() generates full statistical summaries via Polars, including column types, nulls, distributions, and quality scores.
  • Quick Inspection — hr.inspect() returns a fast snapshot of shape, dtypes, and memory usage.
  • Frequency Detection — hr.get_freqs() identifies time-series frequency from a DataFrame.
  • Date Range Detection — hr.date_ranges() finds contiguous date intervals in datetime columns.
  • Anomaly Detection — hr.anomaly_count() flags outliers using the IQR method.
  • 10 Connectors — Binance, FRED, World Bank, SEC EDGAR, YFinance, Finnhub, IMF, GDELT, OpenSanctions, and public datasets.
  • 4 Parsers — CSV, JSON, Parquet, and XML.
  • 7 Canonical Schemas — entity, economic.observation, financial.observation, market.observation, geopolitical.event, security.event, document.
  • Entity Resolution — Country matching with ISO-3166 support and a list of 200+ countries.
  • Dataset Object — The central abstraction that bundles data, metadata, provenance, and lineage.

Design Principles

  • Local first — pip install and start. No cloud account, no API key, no docker daemon required.
  • Interoperable, not replaceable — Built on Polars, Pandas, PyArrow, and DuckDB. Use Hermes alongside the tools you already know.
  • One auditable object — The Dataset carries data and its complete story in a single, serializable package.
  • Honest by default — What is built is documented as built. Planned features are clearly marked.

What's Next

The roadmap for Hermes includes completing the data pipeline stages, adding persistent storage backends, and building out the query engine. Features that are not yet implemented are clearly marked with a Planned badge throughout the documentation.
