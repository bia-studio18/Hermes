What is Hermes?

A Python toolkit for data professionals who need to acquire, profile, validate, and trace the provenance of structured data — entirely on their own machine.

The Problem

Financial, economic, and geopolitical data lives in dozens of places: CSV exports, API endpoints, Parquet files, XML feeds. Each source has its own format, its own quirks, and its own notion of quality. Getting all of this data into a consistent, queryable, auditable form usually means stitching together ad-hoc scripts, manual Excel cleaning, and undocumented transforms.

When something breaks — a column disappears, a date format changes, an API silently returns empty data — there's no record of what happened or why.

What Hermes Does

Hermes solves this by providing a single Dataset object that wraps a Polars DataFrame and carries its entire lifecycle story:

  • Acquire — Fetch data from 10 built-in connectors (Binance, FRED, World Bank, SEC EDGAR, and more) or load it from local files.
  • Parse — Read CSV, JSON, Parquet, and XML into typed DataFrames with the ParserEngine.
  • Normalize — Apply date, numeric, and categorical normalization rules with the NormalizationEngine.
  • Validate — Run checks against a schema or custom rules and produce a ValidationReport.
  • Profile — Generate full statistical summaries with hr.profile(), including column distributions, null rates, and quality scores.
  • Trace — Every operation is recorded in provenance and lineage metadata, so you always know where data came from and what happened to it.

Design Philosophy

Local First

Hermes runs on your laptop. No cloud account, no Docker daemon, no API key for the library itself. pip install hermes-plt and you are working.

Interoperable, Not Replaceable

Hermes is built on top of Polars, Pandas, PyArrow, and DuckDB. It doesn't replace these tools — it makes them work together. You can call .to_pandas(), .to_arrow(), or .to_polars() on any Dataset to get the native frame type you need.

One Auditable Object

The Dataset is the central abstraction. It bundles data, metadata, provenance, lineage, and schema information into a single, serializable package. A Dataset can be saved to disk, reloaded later, and the full audit trail is preserved.

Honest by Default

Hermes documents exactly what works today and what is planned. Features that are not yet implemented raise NotImplementedError and are marked with a Planned badge in this documentation.

Who is Hermes For?

  • Quantitative researchers who need reproducible, auditable data pipelines.
  • Data engineers building financial or economic data warehouses.
  • Journalists and analysts who need to trace claims back to source data.
  • Compliance teams that require provable data lineage for regulatory purposes.
