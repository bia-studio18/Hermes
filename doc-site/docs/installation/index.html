Installation

Install Hermes and its dependencies in one command.

Install with pip

pip install hermes-plt

This installs the hermes package along with the following dependencies:

  • Polars — Primary DataFrame engine for profiling and transformations.
  • PyArrow — Columnar memory format, Parquet read/write.
  • Pandas — Interop via .to_pandas().
  • DuckDB — SQL query engine integration.
  • requests — HTTP client for connectors.
  • lxml — XML parsing.
  • pydantic — Data validation and models.

Python Version

Hermes requires Python 3.11 or later. Check your version:

python --version

Verify Installation

hermes version

Expected output:

hermes-plt 0.2.16

Import Check

import hermes as hr
print(hr.__version__)

Optional Dependencies

The core installation includes everything needed for most use cases. If you plan to extend Hermes with custom backends or features, you may want additional packages:

  • pytest — For running the test suite.
  • ruff — For code quality checks during development.
